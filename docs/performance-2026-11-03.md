# 6× 降速下的滚动性能对比

对比滚动效果修改前后的首页表现。基线为父提交 `1d9e522`（v0.47.4），修改版为 `f76e5dc`：滚动时保留足迹和天气卡片的毛玻璃，并让动态背景继续运行。

测试在离线模拟的 B 站首页上执行，使用 Playwright Chromium 156、1440×900 深色视口，并通过 Chrome DevTools Protocol 将 CPU 限速设为 6×。每轮加载足迹和天气卡片后交替滚动 30 次，修改前后各运行五轮。下表为五轮中位数。

测试机器：Mac mini，Apple M2；8 核 CPU（4 性能核、4 能效核）、10 核 GPU、16GB 内存；macOS 27.2（Build 26B123）。

| 检查 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 滚动场景耗时 | 7832ms | 7893ms |
| 采集到的动画帧数 | 244 | 248 |
| 平均帧间隔 | 32.23ms | 31.75ms |
| 帧间隔 P95 / P99 | 66.7ms / 84.3ms | 66.5ms / 83.4ms |
| 帧间隔超过 50ms | 31 帧 | 30 帧 |
| 帧间隔超过 100ms | 1 帧 | 1 帧 |
| Long Task 总时长 | 52ms | 0ms |
| 背景重绘次数 | 170 | 295 |

两版足迹卡片的计算样式均为 `blur(24px) saturate(1.4)`，动态背景均加载 `random` 模式。修改版背景重绘中位数增加 73.5%，符合滚动期间背景持续运行的预期；整体耗时、帧间隔和长任务数据接近，没有显示明显的整体性能差异。

重绘次数通过两版独立测试构建中的临时计数器统计，计数位置在背景 `draw()` 流程通过无 WebGL 程序或画面无需变化等早退检查之后。该值是背景绘制流程调用次数，不等同于 GPU 最终呈现帧数；计数器没有保留在产品源码中。

本次测试同时记录了 Playwright trace。按清理要求，trace、逐轮 JSON、测试脚本和测试截图均已删除，只保留本报告。五轮样本有限，测试使用离线首页，不代表所有设备或真实 B 站页面的帧率保证。
